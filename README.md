# USA Area Code Atlas

A map game for learning US telephone area codes, region by region.

**Play:** https://clownien.github.io/USA-area-code-atlas/

- **Find the region:** an area code appears; click the part of the map where it rings.
- **Pick the code:** a region lights up; choose its area code.
- **Explore:** click any region to study its codes.

Region borders are approximate. Some of the newest overlay codes are not included.
