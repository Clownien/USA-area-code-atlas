# Area Code Atlas

A map game for learning telephone area codes region by region, in the USA, Canada, Mexico and Sweden.

**Play:** https://clownien.github.io/USA-area-code-atlas/

- **Find the region:** an area code appears; click the part of the map where it rings.
- **Pick the code:** a region lights up; choose its area code.
- **Explore:** click any region to study its codes.
- **Search:** look up any area code, city, state or county in all four countries.

Pick a country with the buttons at the top. Scroll, pinch or use + and − to zoom, drag to move, or jump to a part of the country from the menu. After you answer, point at any region to see its area codes.

Region borders are approximate: they are drawn around the main cities that use each code. Some of the newest codes are not included, and Mexico and Sweden include the main cities and towns only.

Map data: [us-atlas](https://github.com/topojson/us-atlas) (U.S. Census Bureau) and [@geo-insight/data](https://github.com/ibare/geo-insight) (MIT).
